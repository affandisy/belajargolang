Soal Baru – Coffee Shop Ordering System

Tema: Membuat sistem pemesanan di sebuah Coffee Shop.
Tujuan: Melatih pemahaman struct, array/slice, map, perulangan, input/output, dan perhitungan sederhana.
Kesamaan dengan program restoran sebelumnya:

User dapat memilih item dari menu.

Input jumlah untuk setiap item.

Semua menu ditampilkan di ringkasan pesanan (bahkan yang tidak dipilih → 0 × harga = 0).

Subtotal, pajak, tip, dan total akhir dihitung.

Deskripsi Masalah

Sebuah coffee shop bernama Hacktiv8 Coffee ingin membuat program sederhana untuk sistem order mereka.
Menu yang tersedia:

Espresso – $3.50

Cappuccino – $4.00

Latte – $4.50

Mocha – $5.00

Tea – $2.50

Aturan sistem:

Tampilkan menu di awal program.

User boleh memesan beberapa kali item yang berbeda.

User mengetik done jika sudah selesai memesan.

Untuk setiap item yang dipilih, user memasukkan jumlah yang diinginkan.

Setelah selesai, program menampilkan ringkasan pesanan, termasuk item dengan jumlah 0.

Hitung subtotal, pajak 10%, tip 15%, dan total akhir.
